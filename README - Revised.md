# Yamel Interactive Avatar — plain-language README

## What this is
A single web page showing "Yamel", a drawn character in a white hard hat, blue work jacket and headphones. You can click it to start a "Talk with Yamel" experience.

## Who it's for
Visitors to a site that wants a friendly, clickable assistant character.

## What it does today
- Opens in any browser from one file, `yamel-interactive-avatar.html`.
- Clicking the character or the **Talk with Yamel** button opens a player area.
- The player area is an empty placeholder for now. No talking video is connected yet.
- Uses a dark navy (`#0B1426`) and orange (`#FF4F00`) colour scheme.

## How to run it
1. Put `yamel-reference.png` (the reference photo) next to the HTML file.
2. Open `yamel-interactive-avatar.html` in a browser.
