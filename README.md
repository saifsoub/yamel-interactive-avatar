# Yamel Interactive Avatar

**Full production interactive avatar system** built with the `figma-hyperframes-avatar` skill.

## What you get

- Exact visual lock to the reference photo (white hard hat, blue work jacket, headphones, calm confident smile)
- Self-contained interactive HTML embed (dark navy + #FF4F00 orange aesthetic)
- Click → Talk with Yamel flow with player state
- Ready for HyperFrames / HeyGen talking video layer
- GitHub hosted & versioned

## Quick start

1. Open `yamel-interactive-avatar.html` in any browser
2. Click the avatar or the **Talk with Yamel** button
3. The player area expands (placeholder ready for live HyperFrames embed)
